## Ejecutar localmente

### Requisitos

- Node.js 18 o superior.
- npm.

### Instalación

```bash
git clone https://github.com/estefanocarbajal/estefanocarbajal.github.io.git
cd estefanocarbajal.github.io
npm install
npm run dev
```

Vite mostrará la dirección local para abrir el portafolio en el navegador.

## Compilación y despliegue

Generar la versión de producción:

```bash
npm run build
```

Previsualizar la compilación:

```bash
npm run preview
```

Publicar en GitHub Pages:

```bash
npm run deploy
```
